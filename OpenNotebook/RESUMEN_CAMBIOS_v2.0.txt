📋 PROBLEMAS CRÍTICOS RESUELTOS
────────────────────────────────────────────────────────────────────────────────

1. ❌ RUTAS HARDCODEADAS → ✅ CONFIGURACIÓN VIA .ENV
   ──────────────────────────────────────────────────────
   Problema: /home/licjo/chroma_db fijo → no funciona en otra máquina
   Solución: Crear .env con:

     CHROMA_PATH=/home/licjo/chroma_db
     JURISPRUDENCIA_PATH=/home/licjo/jurisprudencia
     COSINE_THRESHOLD=0.50

   Beneficio: Portable a cualquier laptop/servidor

2. ❌ RESOLUCIÓN FRÁGIL DE ALIAS → ✅ VENTANA EXPANDIDA (30 → 100 chars)
   ──────────────────────────────────────────────────────────────────────
   Antes: "De conformidad con el CPEUM..."
          → CPEUM queda fuera de ventana → law="desconocido" ❌

   Ahora: Búsqueda en 100 chars → CPEUM se captura ✅

3. ❌ UMBRAL MUY PERMISIVO (0.68) → ✅ CONSERVADOR (0.50)
   ──────────────────────────────────────────────────────
   Antes: distancia=0.68 acepta como "bueno" = 32% similitud ❌
   Ahora: distancia=0.50 = 50% similitud (conservador para legal) ✅

4. ❌ SIN LOGGING → ✅ LOGGING ESTRUCTURADO
   ──────────────────────────────────────────
   Antes: print() desordenado
   Ahora: logger.info() / logger.debug() con timestamps

   Uso: python OpenNotebook_v2.0.py audit --file borrador.md --verbose

5. ❌ CÓDIGO MUERTO → ✅ ELIMINADO
   ────────────────────────────────
   ARTICLE_PATTERNS estaba definido pero nunca se usaba

6. ❌ METADATOS INCOMPLETOS → ✅ INCLUYE PÁGINA + CHUNK
   ───────────────────────────────────────────────────
   Antes: {"source": "...", "law": "...", "article": "..."}
   Ahora: {"source": "...", "law": "...", "article": "...", "page": "247", "chunk_index": "5"}

⭐ NUEVAS CARACTERÍSTICAS
────────────────────────────────────────────────────────────────────────────────

Comando nuevo: --clear
  python OpenNotebook_v2.0.py ingest --directory /pdfs/ --clear
  → Borra colección antes de ingestión

Comando nuevo: --reingest
  python OpenNotebook_v2.0.py ingest --directory /pdfs/ --reingest
  → Re-indexa todo (útil si cambiaste threshold)

Comando nuevo: --verbose
  python OpenNotebook_v2.0.py audit --file borrador.md --verbose
  → Logs DEBUG completos (debugging)

Archivo nuevo: .env
  Configuración portable sin editar código
